My Interested Research Thoughts:
======
1. Self-Learner [Hard for me due to heavy engineering]: LLMs are not up-to-date, they are not trained with same-day corpus, so there is a delay; However, continuous training with information flow is also unstable. Observing that Recommendation Systems can learn real-time data, how can we deploy a online-learning framework that can learn from real-time data but not shifting general probability?

2. Hyper-Language [Harder]: LLMs trained with code shows significantly better reasoning ability. The quality of training language matters. However, the natural language is becoming the constrain for 'better langauge model'. Is there better representations that can be learned and easy to model (not continuous, like image, vedio, sound) ?

3. Model Mutual Training [Easier]: Go Model can learn from playing with itself. How can Chat Model improve each other with having conversation?
